Crowd Runner

Playing locally: Space jumps, arrow keys steer.

“Connect to S.V.E.R” shows a code to enter at sver.tv/go; tick “May set my board” there and the game brings its own board. It needs this game's client ID from Settings → Developer: open the page as index.html#client=…. A token from Creator Studio works too (it stays in your browser; index.html#token=sver_g_… also works). Without “May set my board” your board needs a button jump, a goal coins, a text input shout and a joystick move.
