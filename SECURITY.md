# Security policy

Please report security problems privately. Do not open a public issue, discussion, or pull request for them.

## How to report

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include:

- what the problem is and where (file, endpoint, or page);
- steps to reproduce it;
- what an attacker could do with it.

We aim to reply within 3 days and to keep you updated until it's fixed. Once a fix ships, we're happy to credit you unless you'd rather stay anonymous.

## Scope

In scope: this repository and the S.V.E.R services at sver.tv.

Please don't test against other users' accounts or data, run denial-of-service tests, or use social engineering. Test with accounts you own.
